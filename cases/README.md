\- 用算式重算對方回報的每一個數字：唯讀審查環境開不了瀏覽器時，拿倉庫裡的常數把實作者回報的數字重算一次；多個數字同時對上，支持回報與程式常數相符；這是算式對帳，不等於重新量測，也不能單獨證明對方執行過量測，還順便算出真正的門檻。這是正面示範、沒有事故，所以不進上面的索引。
