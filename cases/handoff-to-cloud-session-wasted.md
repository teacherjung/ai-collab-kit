# 套件施工交接給開在雲端的工作階段，讀不到桌面檔與本機工具，整場白跑

- 日期：2026-10-01
- 本文條號：D2
- 發生什麼：套件待辦收尾那條線要換一個工作階段接手，實作者寫好交接資料夾、用接手卡片開了新的工作階段，卡片卻把它開在雲端。雲端那一端讀不到這條線離不開的東西：桌面上的交接文件與進度摘要、套件的常設工作樹、錢的攔截器放在本機的固定複本、本機那一家 AI。那一場什麼都做不了：沒改任何檔、沒開 PR；交接資料夾依擁有者指示移到垃圾桶（沒硬刪）。一週後另一條線的接手卡片差一點又開在雲端，才想起這件事沒有寫在任何共用的檔裡。
- 代價：一場工作階段白跑；交接資料夾作廢重寫；教訓只留在對話裡，差一點重演。
- 教訓：套件施工（與任何要用到本機工作樹、倉庫外文件、本機攔截器複本的事）只能交接給開在本機的工作階段；交接前先確認接手方開在哪裡，卡片會開在雲端的就不能用來交接；這一條要寫進共用的檔，不留在對話。
