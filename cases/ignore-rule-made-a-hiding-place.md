# 忽略清單把藏身處做得比刪除更順手

- 日期：2026-08-03
- 本文條號：戊7
- 發生什麼：實作者在同一支變更裡立了「沒用到的程式直接刪」，卻同時在版本控制的忽略清單加一條、又在風格檢查設定裡留一條同名豁免，讓「退役」資料夾既不被追蹤、也不被糾察；獨立審查者實測把檔案放進去，狀態完全看不見、文件考題照樣全綠。改法是把兩份清單逐條寫死在考題裡，任何改動轉紅。
- 代價：一邊說不准藏、一邊把藏身處做得比刪除更順手；修完又被同一位審查者換個寫法繞過去，兩輪審查耗在這一條。
- 教訓：護欄不可以在反方向使力；忽略與豁免清單要逐條宣告在考題裡，而且要讀設定檔真正拿到的值、不要比對文字。
