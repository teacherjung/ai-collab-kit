# 給裁示者的「誤擋 0」是推論不是量測

- 日期：2026-09-24
- 本文條號：J4
- 發生什麼：實作者在一支錢門禁的PR裡請裁示者選修法，選項裡寫「誤擋 0」，讓改行為那條路看起來沒有代價；那個數字只在一份 36 支的必須放行清單上成立，前一個提案的測量也替不了最終方案背書，複審者第四輪就指出這是宣稱過頭。實作者補了一則更正，但裁示者兩天後追問這支「似乎沒有意義」，實作者回去把本機看得到的真工具名全跑一次才量清楚：這支讓 0 支真工具改變結果，而選它要付的代價（多輪複審、裁示者親手在兩側換固定複本並重按信任）在選項裡一個字都沒寫。
- 代價：十二輪複審，裁示者兩側各做一次手工手續；固定複本的指紋已經換過，退回去等於再換一次，錯的成本鎖定了。
- 教訓：裁示者要據此決定的事實先量再講，量不到就寫「沒量過」；推論標成推論；「零」「全部」這類字只寫在量過的範圍內；發現講錯就把原句撤掉或改掉，不是只補一段。
