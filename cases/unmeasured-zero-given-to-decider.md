# 給裁示者的「誤擋 0」是推論不是量測

- 日期：2026-09-24
- 本文條號：J4
- 發生什麼：實作者在一支錢門禁的PR裡請裁示者選修法，選項裡寫「誤擋 0」，讓改行為那條路看起來沒有代價；那個數字只在一份 36 支的必須放行清單上成立，前一個提案的測量也替不了最終方案背書，複審者第四輪就指出這是宣稱過頭。實作者另貼了一則更正，但沒有回去量真工具；兩天後裁示者追問這支的價值，實作者才把當時那個對話看得到的連接器工具，加上券商登記的真名，共 87 個真工具名全跑一次：這支讓其中 0 支改變結果，而選它要付的代價（之後的多輪複審，以及換固定複本、重按信任這類要裁示者到場的手續）在選項裡一個字都沒寫。
- 代價：貼出選項之後又審了九輪（第四到第十二輪，其中幾輪是別的問題）；合併後兩側都要裁示者配合換固定複本、重按信任；固定複本的指紋已經換過，退回去等於再換一次，錯的成本鎖定了。
- 教訓：裁示者要據此決定的事實先量再講，量不到就寫「沒量過」；推論標成推論；「零」「全部」這類字只寫在量過的範圍內；發現講錯就把原句撤掉或改掉，不是只補一段。
