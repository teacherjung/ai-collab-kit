# 考題邊界外推一格連七輪被繞

- 日期：2026-09-07
- 本文條號：己10、子3、子4、壬4
- 發生什麼：一顆保住規則書某一節不被作廢的考題，實作者每一輪都把釘住的邊界往外推一格，獨立審查者下一輪就站到新邊界外面，連續七輪。同族第二支把「這段字在畫面上看不看得見」的判斷交給工具去做，而檔頭寫了一句做不到的絕對保證（「不可能少剝」），審查者每找到一個合法角落都合理判成保證撐不住，二十四輪沒收斂，裁示者問「為什麼審這麼多遍」；第三支又為守住一句話四輪換四種寫法，被表格文法的角落打穿，而先例一個多月前就下過「要嘛寫真正的解析器、要嘛不走」的結論。實作者還在給裁示者的選項裡寫了一句假賣點（「專案目前一個外部套件都沒有」），趁裁前才更正。
- 代價：三支同族合計四十輪上下的審查白燒（第一支十五輪、第二支二十四輪、第三支四輪），每一輪都是花裁示者資源的完整審查；最後真正讓它停下的是去歷史裡量那段程式守到的量（量到 0 就整段砍）。
- 教訓：同一件事連續被抓第三輪就停手問「這道考題到底能證明什麼」，不要再修形狀；護欄說明裡不寫絕對量詞，寫防誰、防什麼、不防什麼；檢查若要重做別人做好的東西（畫面怎麼呈現、某語言怎麼解析）第二輪就該停；砍護欄前先在歷史上量誤擋率與守到的量，把射程照實寫下而不是寫絕對保證。
