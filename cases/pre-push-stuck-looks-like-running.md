# 守門卡住與在跑長得一模一樣

- 日期：2026-09-10
- 本文條號：子4
- 發生什麼：推送前守門跑全卷時掛在一題會另起幾十個子程序的考題上六十三分鐘、日誌完全不動；實作者沒有量任何一項就向裁示者下了結論，說「機器忙、等它跑完」。事後一量：自己的程序全在零負載、高負載來自別的應用，單獨重跑那一支十七秒全綠。
- 代價：空等一小時，外加一句沒量過就交給裁示者的結論。
- 教訓：下「它還在跑」這種結論之前先量：程序活多久、日誌時間有沒有前進、它是不是真的在吃處理器；推送前守門也要有時間上限並印出卡在哪一題。
