# 漏寫「不要合併」、審完直接合了

- 日期：2026-08-23
- 本文條號：己3、庚1
- 發生什麼：發審者給獨立審查者的提示詞寫了「合併鍵由你按」，卻漏寫「先別合併、等掃描跑完」；審查者依常設授權貼完「通過」兩分鐘內就合併了。規矩要求的「第一次通過之後、轉正式之前掃一次」只好在合併後補跑，補掃抓到三條屬實的考題缺口，其中一條是高（一組對照組自己就是空包彈）。
- 代價：一條高風險考題缺口先進主幹，另開一支變更才補上。
- 教訓：給審查者的提示詞一律逐字寫「請勿轉正式、請勿合併」；沒有任何閘看這件事，漏了不會有東西擋你。
