# 收緊判準反而在別處多猜了一次

- 日期：2026-08-28
- 本文條號：戊9、戊8
- 發生什麼：實作者把「發卡銀行名稱有歧義」從猜一家收緊成「不猜」，單看那一層是查不到就不放行；但下游把那張卡移出候選族群後，「該銀行只剩一張卡就自動歸類」的分支反而成立，本來會問使用者的情況靜靜變成自動決定。獨立審查者四輪都沒看到，另開的多視角對抗驗證才抓到。
- 代價：那支變更自己的立論被推翻；若上線，錯歸類會靜靜發生，而不是多按一次選卡。
- 教訓：「查不到就停」是單一層的性質不是全流程的性質，收緊任何判準前要追每個消費端有沒有「只剩一個就自動」的分支，並留一對回歸加對照組考題防恆真；互不重疊視角的對抗驗證能抓到獨立審查者連看四輪都看不到的東西。
