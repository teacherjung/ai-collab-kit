# 給裁示者的留言編號是憑印象編出來的

- 日期：2026-09-21
- 本文條號：J4、J1
- 發生什麼：實作者在當天一支PR的說明裡自述：給了裁示者「一個憑印象編出來的留言編號」。同一支PR在實作者這一方專用的指示檔裡，回報版面講附件的地方，加了一句警語：「附件那一行的每個網址發出去之前先查一次，不憑印象寫編號」。隔天這句照 K1 原樣搬進各方共讀的協作檔。那個編號是在哪一則訊息給的、是完整連結還是只有編號、怎麼被發現的，那支PR的說明與留言都沒寫。附件不是當天才有：9/5 起，同一份指示檔就寫著審查原文放在六段之後的附件；9/6 起，附件改給逐條判定加結論留言的連結。照同一份PR說明的轉述，裁示者當天裁的是把附件固定成每則都有的一行。警語本身點名附件裡的網址，所以那個編號多半出在附件的留言連結裡：這是推論。
- 代價：有紀錄的只有一件：裁示者拿到一個編出來的留言編號（實作者在PR說明裡的自述）。推論：要靠那個編號查核的那一點，等於沒附證據；若它剛好指到別的留言，還會誤導。之後有沒有人因此多花工夫或做錯決定，那支PR的說明與留言都沒寫，私人對話沒查。
- 教訓：附件裡的連結與編號，也是給裁示者的事實：發出前逐一打開，確認指到的是要給的那一則；沒打開查過的，照 J4 標明沒量過，不憑印象補一個看起來像的。
