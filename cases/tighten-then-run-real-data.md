# 判準收緊後真語料整則假紅

- 日期：2026-09-07
- 本文條號：戊8、戊9
- 發生什麼：實作者把待裁清單工具的判準收緊成「行首欄名＋粗體引號，引號裡不准再有引號」，四十四題夾具全綠。拿真語料實跑才發現裁示者的回覆本身就有巢狀引號（他引別人的話），整則被判「形狀不合」，兩題已經回過的問題冒回「還沒回」。改成貪婪比對收到行尾最後一組引號才對，並補一題釘住「原話裡可以再有引號」、用突變證明它會紅。
- 代價：差一步就把已裁的兩題當成沒裁；夾具全綠給了假的安心，靠實跑真語料比對前後分類數字才攔下。
- 教訓：收緊判準的失敗方向是假紅，而假紅在自己寫的夾具裡永遠看不到——推送前一定拿真語料跑一次比對前後分類數字，跑出來的形狀補成考題釘住並用突變證明會紅；中文引號、括號天生會巢狀，寫「不准出現結束符」之前先問它會不會自己嵌自己。
