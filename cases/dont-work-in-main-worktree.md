# 在主目錄施工提交落到別人分支

- 日期：2026-09-02
- 本文條號：丁2
- 發生什麼：實作者在主目錄施工，提交的那一瞬間另一個工作階段把主目錄切到它自己的新分支，提交因此落到別人的分支上。成果沒丟（把自己的分支指回那顆提交就接回來了），但對方有未提交的改動，絕不能碰它的分支，只能改用自己的樹並等對方自己清。同一天又在乾淨的工作樹上暫存後無條件取回，取出的是躺了半個月的舊暫存，污染工作樹並產生衝突。
- 代價：提交落錯分支要手動接回；一次工作樹被舊暫存污染。
- 教訓：主目錄是所有工作階段的公用地、切分支沒有鎖；實作一律在自己的常設樹，主目錄只做短動作且動前先看狀態與分支名；暫存前先確認真的有存到再取回。
