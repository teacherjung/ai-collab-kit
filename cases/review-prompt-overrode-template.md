# 送審提示由實作者自己寫：限定範圍、不准跑整份考題、蓋掉清單

- 日期：2026-10-03
- 本文條號：F3、F1、F7
- 發生什麼：PFW #655 三輪的送審提示都是實作者每輪自己寫的：第 1 輪寫「第 1〜12 項不能漏」，第 2 輪沒提清單，第 3 輪自己規定回報格式（發現、對帳、實際驗證、殘餘風險），複審者照著寫，結論裡沒有逐項清單；合併前的檢查只看結論第一行，沒人發現。往前查：從 PFW #647 起連續 17 輪，提示都寫「不要跑整份考卷」，等於實作者替複審者決定；#655 三輪的複審者因為送審時沒附放行清單，都跑不了考題，突變全靠讀程式推演，發審的一方讀到「被擋」也沒轉告裁示者。裁示者 10/3 選「固定範本，實作者只填事實」；同一天裁：整份考題跑不跑由複審者「獨立判斷，實作者不可以給指導或建議」，突變「實作者備副本，複審者只改副本」，結論「複審者自己貼；貼不成就輸出全文並標明未貼」；「通過」那一則要有「本輪實際用的設定」「清單逐項結果」兩個固定小標。
- 代價：#655 三輪複審都沒有實際跑過考題；第三輪的結論沒有逐項清單，事後查不出每一項有沒有看；17 輪的提示替複審者先做了判斷。
- 教訓：送審提示的格式由範本定，實作者只填事實；複審者實際用了什麼設定、跑了哪些考題、哪些指令被擋，寫在結論開頭的固定小標下，缺了那則「通過」不算數。
