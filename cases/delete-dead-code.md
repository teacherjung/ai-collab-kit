# 死程式搬到退役夾反而混進別支

- 日期：2026-08-03
- 本文條號：戊6、戊9
- 發生什麼：裁示者裁「未來沒有用的程式都直接刪除」，起因是一支已裁「規則收下、工具不收」的兩萬多位元組舊工具還躺在放合併閘的資料夾裡，讓整個資料夾看起來都是活的。實作者試過折衷把它搬到本機退役資料夾，結果是錯的：未追蹤的檔沒有備份、搬動不是備份，而且它在切分支時忽隱忽現，因為另一支變更的「全部加入」把它收進版控了。同日另定「檔名一律用英文」，既有非英文路徑凍結只出不進、由考題盯著。
- 代價：以為有東西在刪檔案、追了一陣；兩條規矩另開一支變更入冊。
- 教訓：要嘛進版控、要嘛刪掉，不要留在沒人備份的角落；刪的是程式碼不是決定，理由先寫在別處（「死程式直接刪」本文沒有專條，只有檔名那條對得上戊6）。
