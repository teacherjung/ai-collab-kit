# 改出來的審查提示漏改編號

- 日期：2026-09-07
- 本文條號：己3、庚3
- 發生什麼：實作者把上一支的審查提示詞改成新一輪，漏改了變更網址、受審版本、審查樹路徑、留言編號四處；獨立審查者自檢發現樹的版本與指定的對不上，停下不審，整輪沒有產出。後來同族又踩兩次：提示詞前面寫「通過就合併」、檔尾卻殘留「不要合併、等掃描」，審查者通過後照檔尾辦沒合併；掃描紀錄從上一支改出來，把上一支的失敗描述抄進了這一支。
- 代價：一輪審查白燒（約八萬 token 的額度）、多發一次純合併回合、掃描紀錄抄錯被審查者抓到。
- 教訓：從上一支改出來的提示詞與紀錄，發射前逐項核對編號與版本、搜尋舊編號與互相打架的指令；掃描紀錄每一句都從這一支的回覆原文抄。
