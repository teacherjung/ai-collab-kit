# 重疊的草稿變更擋住快合併的那支

- 日期：2026-08-29
- 本文條號：丁3
- 發生什麼：實作者開了一支草稿變更，欄位裡寫明「與在途那支重疊、等它合併後才送審、不會搶」；但跨變更試合併閘把兩支真的合起來跑三關、不讀欄位裡的意圖，結果還沒送審的這支擋住了已完成六輪審查加掃描、走到合併最後一步的那支，而那些檔案本來就是對方先預約的。監督線發了二十分鐘限時協調，靠暫時關掉這支才解開。裁示者當天排定把「重疊就讓道」寫進規則書，同日入冊。
- 代價：對方走到最後一步被卡、一場限時協調；預約制形式上遵守、實質上被破壞。
- 教訓：機器閘的世界裡「開著的變更」就是衝突源，聲明是寫給人看的、閘看不見；與在途預約重疊就晚開，或開了立刻暫關並留言寫明「讓道、非放棄、誰負責重開」。
