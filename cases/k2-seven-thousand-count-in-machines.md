# K2 上限放寬到七千，數法搬去機器表

- 日期：2026-09-26
- 本文條號：K2、K1
- 發生什麼：前一天裁示者才把 K2 上限從三千放寬到四千、說好 G〜K 走完再瘦；9/26 走到 K2，他把條文改成「不超過7000字」貼回來（沒有另附理由），同時拿掉數法那一行（節標題、條號、句尾標籤、格式記號不算）。實作者建議留在 K2（考題照那一行數，拿掉之後七千字不知道數什麼）；裁示者回拿掉是因為「我希望規則越簡單越好」，實作者改建議寫進機器表 K2 那一列、規則不加指路。裁示者沒照「不加指路」，自己在條文補一句「數法規則內建在機器表裡」；實作者建議改字成「數法寫在「機器表」」並隨即記成定案（這兩處改字裁示者沒再回），考題寫死的 3000 留待施工時改成 7000。
- 代價：沒有事故；若維持四千，收尾量到的正文不論哪種數法都超過（4,173 或 4,528 字），就得再砍剛逐條定案的字（推論）；數法同一天出現兩個說法：實作者向裁示者解釋時說關鍵詞的「」不算，收尾報的 4,173 字也是扣掉「」算的；但考題的數法前後沒變、一直把「」算進去，定案頁寫的也只扣粗體與灰底框記號，施工前照考題重算是 4,528 字，落地的機器表照考題寫「」照算——錯的是那一句解釋（兩個數都遠低於七千，上限不受影響）。
- 教訓：規則本文只留上限和一句指路，怎麼數只寫一份、放在守它的那一列，考題與對裁示者的解釋都照那一份；上限一改，考題寫死的數字同一支一起改。
