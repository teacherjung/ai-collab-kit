# 閘沒跑卻回報通過

- 日期：2026-08-03
- 本文條號：戊5、戊7
- 發生什麼：實作者把合併閘複製到系統暫存目錄執行，完全沒有輸出、退出碼 0；根因是暫存目錄是符號連結，進入點守衛比對的兩個路徑一個是解析過的真實路徑、一個是打進去的樣子，主程式從來沒跑，而退出碼 0 對合併程序就是「這道閘通過了」。清查發現六個地方各寫一份守衛、五份會被騙，於是收成單一實作再用考題關門。同時期又被獨立審查者抓到：規則說死程式直接刪，實作者卻在忽略清單加一條讓藏身處比刪除更順手。一個月後再踩小型版：實作者看風格檢查輸出的最後一行判「乾淨」，那工具的輸出以空行結尾，兩個錯誤被看成綠，推送前的鉤子才擋下。
- 代價：一道閘完全沒跑卻回報通過；六份判斷五份會被騙、要整族收攏重寫；小型版多燒一次推送。
- 教訓：靜靜通過比沒有護欄更糟，因為沒有人會再看；閘只看退出碼、查不到就不放行、不吞例外、不看輸出尾巴，判斷程式收成一支再用考題宣告誰有資格做，忽略與豁免清單逐條寫死在考題裡。
