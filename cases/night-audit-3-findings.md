# 代理自報全綠與並行樹互撞

- 日期：2026-09-06
- 本文條號：丁2、子4
- 發生什麼：第三輪夜間稽核用近三百個代理並行六條線做突變，代理回報的「全綠」被拿去逐條用全卷考題重做，發現約百分之四是誤報（其中兩條其實有行為題守著，代理只跑了最可能相關的幾支考題檔）。同時六條線共用同一個暫存根目錄與同名腳本，其中一條的突變落到別條線的樹上，撞了沒有任何東西擋。
- 代價：三條誤報差點進修補批次；一條線的樹被別條線的突變改到，靠那條線自己發現還原。
- 教訓：代理自報結果的射程只有它實際跑過的範圍，複驗要寫進流程不是可選；並行的每條線暫存目錄各自獨立，工具要有「不在自己樹底下就中止」的硬閘。
- 來源：2026-09-06 第三輪夜間稽核（無對應變更編號）
