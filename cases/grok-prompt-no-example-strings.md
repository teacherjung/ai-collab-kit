# 提示詞要具體字串、整遍掃描判事故

- 日期：2026-08-31
- 本文條號：庚2、庚3
- 發生什麼：掃描發射者在提示詞裡要求掃描器「給具體字串、能寫成考題的那種」，掃描器照做，回覆裡出現了憑證形狀的字串。那些字串逐字不在材料裡、排除集合接不上，驗屍步驟判成「盒子外才有的內容」＝事故，整遍掃描作廢。這是連續第三次事故、也是第一次連重算都做不到的：事故路徑把工作階段紀錄全刪了，不可能誤報的那一族零命中、幾乎確定是假警報卻證明不了。
- 代價：整遍掃描作廢、以「未執行」收口；分辨真假所需的證據被事故路徑一起丟掉。
- 教訓：問漏報路徑要問機制不問字串，需要例子時請它描述不要寫出；疑似破口的處置要保全去機密的證據，否則真假永遠分不出來。
