# 純考題變更也把別檔的劃界句弄成假話

- 日期：2026-09-04
- 本文條號：子5、子3
- 發生什麼：一支只補四題考題的變更，讓另一支考題檔頭的誠實劃界句「這件事本檔沒做」變成假話（新題已經做了）；獨立審查者第二輪通過後，掃描器才抓到。實作者改句時又寫「本檔末題」「已在該檔補題」，第三輪再被抓（按位置指題、寫別處現況與時態），第四輪才過。
- 代價：掃描一條回頭改、多一輪審查。
- 教訓：新增考題後先用「本檔沒做／尚未／目前沒有」這類字眼掃整個倉庫，看有沒有被自己弄假的；同檔指題只用題名關鍵字，跨檔引用不寫現況與時態。
