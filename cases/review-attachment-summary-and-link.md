# 審查附件改摘要加連結

- 日期：2026-09-06
- 本文條號：癸2、己7
- 發生什麼：六段回報之後原本要原樣貼審查者的回覆全文，裁示者讀的負擔太重；實作者問他要「隨時可查」還是「每輪被塞原文」，他裁選「可查」：附件只給逐條判定（屬實·已修／屬實·進待辦／誤報，要問他的標「待裁」、計入總條數）加結論留言連結，原文留在變更上、他問才貼。同時發審提示要求審查者每輪自報條數、對上一輪的逐條處置對帳。
- 代價：沒有事故代價；這是一則裁示，換掉了原本「原文照貼」的附件形狀。
- 教訓：給裁示者的審查結果是「可查」不是「塞原文」：逐條判定加連結，原文他問才貼。
