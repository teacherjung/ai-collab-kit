# 雲端檢查紅了八輪沒人看

- 日期：2026-08-15
- 本文條號：戊3、辛3
- 發生什麼：實作者本機三關全綠，雲端兩個作業卻從第一顆提交起就紅；實作者與獨立審查者都在同一種作業系統上跑三關，八輪審查沒有人看過雲端結果，直到通過後要跑合併閘才第一次看。病灶只是考題挑了一個雲端機器沒有的殼層。後來另一支又踩到：轉正式會重新觸發一輪雲端檢查，實作者抓到的是前一輪的綠就發射合併，代合併方到場時檢查還在跑、照規矩停下沒合併。
- 代價：八輪審查等於沒有那道關；雲端紅燈從第一顆提交拖到通過後才發現，再補一輪修復。
- 教訓：兩個把關者用同一套眼睛，那道關就等於不存在；送審前與合併前都要自己看雲端三關對目前版本真的跑完且綠，轉正式後要等新一輪跑完再確認。
