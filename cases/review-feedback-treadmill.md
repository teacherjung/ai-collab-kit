# 審查回饋無條件全改的跑步機

- 日期：2026-08-05
- 本文條號：己6
- 發生什麼：實作者把審查者提的每一條都回頭改，一改就推翻上一輪結論、再送審又生出新意見，輪數自己會長。當天定下只有三種情況才回頭改（考題沒在守宣稱的東西、註解或題名的保證撐不住、真的產線錯誤），其餘進待辦、不再為它多開一輪。
- 代價：審查陷入無限迴圈，每輪一次返工。
- 教訓：只有那三種情況值得多開一輪，其餘寫待辦；問法是「這一輪提的，是使用者會受害，還是考題可以更漂亮」，是後者就收手。
