# 「沒有明文」與「這張表上沒有」是兩句話

- 日期：2026-09-10
- 本文條號：子4
- 發生什麼：查核工作流的結論寫「這一側兩條根本沒有明文」，實作者照抄進待裁問題、裁示留言的操作化（＝把一句裁示改寫成可執行的條文）、表題與變更說明。掃描器在規則書別處找到反例：規則本身在審查循環表、一句話總綱、合併手冊都有，缺的只是第一眼那張權威表上的字。查核那組人推翻了十一條，這一條漏網，因為他們查的是那張表、結論卻寫成整本規則書。
- 代價：裁示的理由是假的，要另貼一則公開更正；裁示內容本身不變。
- 教訓：查核結論的射程等於它實際查過的範圍，寫進文件前先問「它查的是哪幾份」；「沒有明文」這種全稱否定句，寫之前自己先在整份規則書搜一遍同義句，有一處命中就不能寫。
