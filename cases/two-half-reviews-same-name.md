# 兩份審查各看一半

- 日期：2026-08-02
- 本文條號：己2
- 發生什麼：同一支變更上出現兩份都自稱同一審查角色、結論相反的留言：一份「通過可合併」、一份「需修改後再審」，平台上兩則長得一模一樣。兩份其實都對，只是一份查版面結構、一份查金額口徑與格數；後者抓到五個突變全假綠（四個數字不走共用格式器、資料列少一格整排錯位）。修法＝固定維度清單，不論作者的重點清單寫什麼一律全跑。
- 代價：「最後一則說通過」差點成為事實上的放行。
- 教訓：審查者每輪固定維度全跑，不由作者的重點清單決定看哪裡；否則兩份審查各看一半、合起來還是漏。
