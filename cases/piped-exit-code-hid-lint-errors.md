# 管線吃掉退出碼，四條錯漏網

- 日期：2026-07-24
- 本文條號：戊2、戊5
- 發生什麼：實作者手動跑風格糾察時，把指令接到管線（＝把前一個指令的輸出接給下一個指令）後面再印退出碼（＝指令跑完回報成敗的那個數字，零＝成功），印出來的是管線最後一段的退出碼、不是糾察本身的，於是把「有錯」讀成「乾淨」。那次實際上有四條風格錯誤，是推送前鉤子（＝推送之前自動跑型別、風格、測試三關的本機腳本）把整次推送擋下來才攔到。當天就把教訓寫進規則書：手動跑三關一律直接看命令自己的退出碼。
- 代價：那一次自報的「三關全綠」是假的，四條錯誤差一個動作就推上遠端。
- 教訓：人自己跑一遍、自己宣告綠，證明力接近零——三關要由推送前那道自動門跑，手動跑時也只認命令本身的退出碼。
