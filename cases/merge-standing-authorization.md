# 審過即合併的常設授權

- 日期：2026-08-13
- 本文條號：A5
- 發生什麼：先前每支變更審查通過後，實作者都會停下來再問一次「要合併嗎」。裁示者當天的原話只有一句：你自己完成後，就請審查方依程序合併；三週後入冊時他確認不論誰實作都對稱適用、而且隨時可收回。入冊那支把它操作化成條件式授權——結論要帶合規標頭（＝結論留言開頭那組固定欄位）、閘全回零（＝自動檢查都回報成功）、雲端檢查全綠，按鍵的仍是審查方，授權只涵蓋合併不含開新題目，停問規則與絕對邊界都不受影響——這些條件是實作者寫的，不是他說的。
- 代價：沒有事故；代價是裁示者每支被問第二次。
- 教訓：把「決定」與「執行」拆開：預先授權免掉的是再問一次，不是誰按鍵；把裁示落地成條件時要標明哪些字是他說的、哪些是自己加的。
