# 回報不寫已經解決的問題

- 日期：2026-09-30
- 本文條號：J2
- 發生什麼：一則進度回報的「要你注意的」寫了「改的過程中，考題抓到一個會讓總覽整頁壞掉的問題，已經修好」。擁有者回：這樣的回報沒有必要，問題已經解決了，他要減少自己這邊的負擔、專心決策。問他要不要寫進規則，他選寫進套件的通用規則、以後的專案也適用。原本 J2 的「只縮過程敘事；錯誤、風險、要動手的事照報」會被讀成過程中已經修好的錯也要報；改字前把新舊兩句給擁有者看，他點頭（10/1）。
- 代價：沒有事故；擁有者每次多讀幾行對決定沒有用的過程細節——回報是寫給要做決定的人看的，他讀的每一行都是成本。
- 教訓：過程中抓到、已經修好的問題不寫進給裁示者的回報，留在「PR說明」給審查的人查；還沒解決的錯誤、風險，以及要他動手或決定的事照報；成果與其餘各段照 J1 的七段寫。
