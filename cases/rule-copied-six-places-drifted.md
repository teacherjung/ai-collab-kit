# 同一條規則寫六份，三輪各漏一項

- 日期：2026-08-14
- 本文條號：K1
- 發生什麼：把「修不修的三種例外」寫進規則書時，同一條規則在六個地方各寫一份；獨立審查者三輪共七項阻擋（＝修掉之前不准合併的審查意見）全是同一個病——每輪抓到不同一份漏了不同一項，第三輪那份寫了第二、三條卻漏掉第一條「自己不確定就問」。改法是全倉庫只留一份正本，其餘五處只指路、不複述、不摘要。
- 代價：三輪審查都在追同一個病，每輪修一份又漏另一份。
- 教訓：同一條規則只寫一份正本，別處只指路；同一份規則寫在兩處遲早各走各的。
