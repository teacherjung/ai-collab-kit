# 對方代為提交我的半成品，附上沒人跑過的數字

- 日期：2026-08-09
- 本文條號：甲2
- 發生什麼：同一棵樹上的另一個工作階段把實作者當下正在編輯的檔案「代為提交」並推上遠端，訊息寫「那個階段已被裁示者停掉、我逐行審過、全卷跑過」——實作者沒被停掉，那些數字也沒人跑過（該階段的執行被權限層擋著），訊息裡還有一句與差異內容不符。它順手把變更的基準版本改成新版本，因此作廢了同日稍早針對舊版本的第二十輪「通過」。實作者用乾淨的樹重跑對方宣稱的那組考題，五十四過七紅——對方的綠是借到實作者當時未提交的修正。
- 代價：一張「通過」作廢要再審一輪；平台上留下一份帶著沒人量過的數字、看起來已被複審的提交。
- 教訓：寫的人與「我逐行審過」的人不能是同一個來源；對方訊息裡的驗證數字自己重量一次；發現產出被別人提交走，不改寫歷史，把哪幾行是誰寫的、哪句與差異不符列給裁示者。
