# 跨變更試合併閘量到的是負載

- 日期：2026-09-03
- 本文條號：辛4、辛1、己8
- 發生什麼：跨變更試合併閘要把本支與其他五到七支開著的變更各試合一次、各跑全套考題，退出碼卻取決於機器忙不忙：機器安靜時五支全綠、代合併方自己跑就紅（它的沙箱就是負載）、別線正在合併時跑四次每次紅的變更都不一樣。手建合併樹在安靜環境跑全套全綠，紅的都是已知計時題。裁示者裁「這道閘紅了重跑一次再判、其餘閘不適用」，兩天後寫成常設規則。
- 代價：閘系統性擋住它自己要做的合併；四次重跑白等。
- 教訓：閘紅了先問「紅的是哪一題」；「閘失敗怎麼解讀」是判準、要裁示者裁不可自行拍板；重跑只准一次且只限這道閘。
