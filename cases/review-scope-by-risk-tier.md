# 一支排版 PR 審了三輪、九個半小時：審多深、掃不掃改成照風險級別查表

- 日期：2026-10-02
- 本文條號：D4、F2、G1
- 發生什麼：原專案一支畫面排版與篩選的 PR（PFW #655）審了三輪、整份考題跑了 21 次、前後約 9.5 小時，其中約 7 小時在等。每一輪複審都把整支從頭全審；第 2、3 輪送審時開了自動模式，各派了 3 個、5 個助手（第 1 輪派了幾個沒有紀錄）。裁示者 10/2 起逐條檢討，檢討的一方量了兩組資料：一組畫面 PR 在第 2 輪以後才抓到的 16 條真錯，15 條落在第 2 到 4 輪；6 支高風險 PR 第 8 輪以後還擋下 21 條使用者會遇到的真錯，只核差異的話約四分之一會漏（讀留言與各版差異判斷的，沒重現）。裁示者 10/3 定案：風險分高中低、由機器依檔案先算、實作者只能往重調、複審者第 1 輪核實；高風險每輪全審，中風險第 8 輪起、低風險第 4 輪起只核差異，修正輪改動很大或碰到重要的東西時，實作者或複審者都可以改回全審；高、中掃描，低不掃。
- 代價：一支排版 PR 約 9.5 小時、整份考題 21 次；當時沒有任何規矩說哪一種 PR 可以審得輕一點。
- 教訓：審多深、掃不掃，照風險級別與輪次查表，不由每一輪送審的人臨時決定；只核差異的輪次，最常抓到真錯的那幾項仍看整支；高風險的後段輪次資料顯示還在抓真錯，不省。
