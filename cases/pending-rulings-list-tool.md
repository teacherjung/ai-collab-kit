# 待裁清單工具不是閘

- 日期：2026-09-06
- 本文條號：D1
- 發生什麼：裁示者問實作者「三天之後你真的會記得嗎」，實作者老實答不會（沒有鬧鐘，只有記憶檔與剛好想起），照固定形狀給三個選項，他裁「1. a. 做」＝做一支開工時印出「問了他還沒回」的問題的小工具。工具只向平台問兩種資料（誰提了問題、誰回了）、判準只看留言第一行、配對靠較晚的留言引較早的提問網址；「引用寫在哪裡才算數」寬窄不一，由裁示者當支另裁「只認寫在留言最外層的」。工具本身不是閘，開工那一方沒去跑，清單就等於不存在。
- 代價：這一則沒有可單獨歸屬的量測——同一支的完整審查輪數只記在 [absolute-guarantee-invites-blockers](absolute-guarantee-invites-blockers.md)，這裡不重複計；能歸屬這一則的只有「工具擋不了任何事」這個性質。
- 教訓：開工先看清單、沒回的不自己拍板，靠的是每次開工都跑一次，不靠閘擋；工具判準的寬窄由裁示者定，不在審查裡磨。
