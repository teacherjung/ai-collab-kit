# 留痕只認最外層

- 日期：2026-09-08
- 本文條號：壬3
- 發生什麼：裁示者 09-07 裁「引用網址必須寫在留言最外層才算數」；實作者把它搬進規則書時順手寫了「放進引言的不算」，但工具只看行首前綴：引言的懶續行在平台上仍渲染在引言裡、工具卻當最外層，還沒回的問題會被靜靜關掉；獨立審查者兩輪沒看到，掃描器一掃就中。同支掃描還抓到實作者把整串操作細節寫在裁示者只有一個字「a」的落款底下。修法＝緊接引言的行也當看不見（往收緊修）；落款拆成「他裁的就是這一句」＋「下面是實作者的操作化」。
- 代價：一則引用它的留言就能把還沒回的問題靜靜關掉，而裁示者的原話被摻進不是他說的字。
- 教訓：裁示留痕只認最外層、貼出後不編輯，他的原話逐字與實作者的操作化分開標。
