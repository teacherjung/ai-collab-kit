# 角色欄寫了查表外的名字

- 日期：2026-08-18
- 本文條號：F3、F4
- 發生什麼：發射（＝下指令把一輪審查跑起來）提示詞把標頭的角色寫成「獨立審查者」，而閘（＝合併前自動跑的檢查）的角色查表只認固定幾個名字，判「看不出是誰」；審查者兩則真結論（一則抓到真問題、一則通過）整則收不進閘，身分讀不出＝重述也救不了。最後動用裁示者特准豁免，並請同一位審查者以可讀身分再給一次結論。
- 代價：兩則真審查作廢，動用裁示者特准，多一輪補結論。
- 教訓：逐字字串有三組不是兩組——結論、來源、角色；發提示時整行標頭逐字給、含角色。
