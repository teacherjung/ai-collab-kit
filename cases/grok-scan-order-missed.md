# 漏寫「不要合併」、審完直接合了

- 日期：2026-08-23
- 本文條號：己3、庚1、庚4
- 發生什麼：發審者給獨立審查者的提示詞寫了「合併鍵由你按」，卻漏寫「先別合併、等掃描跑完」；審查者依常設授權審完就合併，複審後掃變成合併後才補跑，補掃抓到三條真發現（含一條高），缺口已經在主幹。兩週後再犯一次：提示詞寫「之後請你代執行合併」本意是描述下一步，審查者讀成指令，貼完通過三分鐘內自己轉正式並合併，也沒留合併結果留言。
- 代價：一條高風險缺口先進主幹再補修；第二次合併沒留合併結果留言。
- 教訓：審查輪的提示詞一律逐字寫「請勿轉正式、請勿合併」，「之後會怎樣」不寫進給審查者的提示詞；沒有任何閘看這件事，漏了不會有東西擋你。
