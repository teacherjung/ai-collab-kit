# 考題餵自己假名字永遠綠

- 日期：2026-09-02
- 本文條號：戊8、戊7
- 發生什麼：程式拿外部世界定義的識別字去比對，考題的夾具與期望值都是從正式程式抄來的同一份字串，名字寫錯照樣全綠，那條路好幾個月靜靜匹配不到，同一張表還有兩顆同病。實作者為此補了一支查核腳本，為了不讓已知舊帳永遠紅而加了豁免清單，獨立審查者連三輪在那份清單上找到高風險問題，裁示者裁定撤下腳本、只合併識別字修正。另一個反咬：已停用的識別字會從最新官方清單消失但歷史資料裡仍有大量真資料，第一版判準寫成「必須在最新清單裡」差點誤殺正確程式。
- 代價：錯名字躺了數月沒被任何考題抓到；查核工具三輪審查後整支撤下。
- 教訓：先問「哪一條考題會因為名字是假的而紅」，答不出就要把外部真相帶進來；會豁免的清單本身就是攻擊面，防呆工具比它防的東西還複雜時正解是撤下、不是再修一輪。
