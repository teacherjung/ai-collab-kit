# 擁有者的常設指示只有一方知道：43 則裡 22 則另一方讀不到或只讀到一部分

- 日期：2026-10-03
- 本文條號：K6
- 發生什麼：檢討 PFW #655 時發現，第三輪的重設定源頭是擁有者只對其中一方 AI 說過的一句話。檢討的一方派人把擁有者 7/26 以來對那一方說的 345 則訊息全部掃過：43 則是跨PR都適用的常設指示，只有 5 則寫進了兩方都會讀的檔；22 則只在那一方的對話裡、或只寫了一部分，而且會影響另一方，例如「另一方暫停實作、改由這一方實作」「手機版先不動」「不要橘色焦點框」（共用檔當時寫的正好相反）。同時量到：那個專案的指示檔太大，其中一方只自動讀到前 24%；另一方因為資料夾裡另有一份它專用的指示檔，完全不讀共用的那一份。擁有者逐則勾選 23 則（那 22 則，加上另一方那邊只記在自己筆記裡的 1 則）：還有效 19、已失效 1、要改 3，並同意立一條兩方都適用的規矩：「你下了跨 PR 都適用的指示，收到的那一方當下就寫進兩邊都會讀的檔，不能只留在對話或筆記裡。」
- 代價：一支排版 PR 的第三輪照的是擁有者 8/10 只對其中一方說過、一直沒撤回的指示，另一方完全不知道有這一則；另一方若在那段時間開工，會照舊實作、會順手調手機版、會做出擁有者不要的橘框（推論：那時另一方正好暫停實作，沒有實際撞上）。
- 教訓：常設指示寫在哪裡（一份兩方每次都完整自動讀進去的檔）和誰去寫、什麼時候寫是兩件事；收到的那一方當下寫進去、附日期與原話，改了或作廢了一樣當下改。
