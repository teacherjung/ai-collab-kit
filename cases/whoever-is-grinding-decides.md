# 誰在磨誰拍板

- 日期：2026-09-10
- 本文條號：甲1、己6
- 發生什麼：規則書把「單條審查回饋修不修」寫死給某一個角色名，那是照當時的常態分工寫的；改成兩邊都會實作之後，換人實作時同一個決定會同時落到兩個人頭上。實作者建議這句維持不動，理由是「被審的人可以自己決定不理會審查會侵蝕不變量（＝任何情況都不准被打破的那條底線）」，裁示者當場推翻（要旨）：另一方實作、這一方審查時，由實作那一方判斷要不要接受審查結果。修法把整族主詞換成「在磨的那一方（＝這一支的實作者）」，並補一句劃界——作者的裁量只管「這一條要不要動手」，管不到這一支能不能合併，那由複審結論閘（＝合併前自動檢查最後一則結論的關卡）擋著。
- 代價：這支跑到第九輪才通過、外加一次掃描（其中四輪是在同支順帶修的留痕（＝把過程留成公開紀錄）格式與它的考題假綠（＝該紅卻是綠的）上打轉），而實作者原本給裁示者的建議是錯的。
- 教訓：規矩裡的主詞要寫座位（在磨的那一方），寫成名字只是把當時的常態分工當成規則；實作者對規則本身的建議也會錯，該問就問。
