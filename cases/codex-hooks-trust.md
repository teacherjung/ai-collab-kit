# 錢的攔截鉤子沒按信任就靜靜跳過

- 日期：2026-09-01
- 本文條號：乙1、戊5
- 發生什麼：禁區（動錢）攔截器裝在獨立審查者那一側工具的鉤子裡，但那個工具的每條鉤子都要裁示者在互動介面上親手按過「信任」才會執行，沒按之前它一聲不吭地跳過，不擋、不警告、零訊息。調查當天實測才發現那一側的鎖根本沒上膛，補按信任後對照執行痕跡確認它真的在跑；過程中面板的「啟用／停用」開關又被誤當成信任鍵一次。裁示者拍板：全域那份鉤子已信任在跑，專案那份內容相同純屬冗餘、刻意停用，不要當 bug 修回去。
- 代價：以為有鎖、其實沒鎖，直到專門去查才知道；改版時全域那份要手動同步再重按信任，否則保護停在舊版。
- 教訓：護欄沒有證明自己有在跑等於沒有；推論「那邊有鉤子擋著」之前先查它的狀態紀錄與執行痕跡，靜靜通過比沒有護欄更糟。
