# 審查樹清理清空主目錄

- 日期：2026-08-02
- 本文條號：己1
- 發生什麼：審查用的工作樹以符號連結借用主目錄的套件目錄；清理暫存工作樹時刪除動作順著連結進去，主目錄的套件被清空，裁示者的應用程式立刻起不來、錯誤訊息指不到真因。同時期審查者在同一目錄裡看到實作者 rebase 切分支十幾次、樹在腳下移動。08-04 裁示者裁「實作常設、審查拋棄」：審查樹每支一棵、釘住受審版本，由發審者備與收，審查者不建樹、不裝不刪套件。
- 代價：應用程式停擺一次，錯誤訊息完全指不到真因。
- 教訓：審查樹是拋棄式的、由備樹的人負責生與死，審查者在裡面只讀，不裝不刪。
- 來源：2026-08-02（事故）／2026-08-04（裁示）
