# 契約句沒跑過工具就寫進規則書

- 日期：2026-09-08
- 本文條號：子4、戊8、庚1
- 發生什麼：實作者把「引用網址必須寫在留言最外層才算數」搬進規則書時，順手列了排除清單「引言、縮排、圍欄、註解都不算」，卻沒有把清單上每一種寫法餵給正式判斷函式跑一遍。獨立審查者兩輪沒看出問題，掃描器一掃就中：其中一種寫法（引言的懶續行）在平台上其實仍渲染在引言裡、工具卻當它是頂層，契約說「不算」、工具卻「算」，還沒回的問題會被靜靜關掉。分岔往收緊方向修；同族下一支又因「從散文抽現行規則」審了十一輪。
- 代價：兩輪審查沒抓到、靠掃描才抓到；同族下一支十一輪。
- 教訓：契約句列出的每一種寫法都要先讓工具真的跑過、結果貼進變更說明；外部渲染的宣稱要實測不能猜；分岔往收緊修。
- 來源：#580（同族 #582）
