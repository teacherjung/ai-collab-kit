# 拿到通過後順手再改，通過作廢、多審四輪

- 日期：2026-10-03
- 本文條號：F6、F2
- 發生什麼：PFW #650 只改了約 50 行樣式，審了 5 輪；後 4 輪都是拿到通過之後又動了程式，版本一變通過就作廢、只好重審。檢討 #655 時實作者原本提「拿到通過後不再動程式，非阻擋的全進待辦」，擁有者不同意：「如果掃描後發現有錯誤也應該立即修正就應該做，不應該限制通過就不動程式。」實作者改成用 F6 現成的六種分：通過後才發現的（不論是掃描、複審者還是擁有者發現的），屬於那六種就立刻修、修完再審一輪；不屬於的列待辦、不動程式；修完那一輪中、低風險只核差異，高風險照舊全審。擁有者選「A」。
- 代價：一支約 50 行的樣式 PR 多出 4 輪複審。
- 教訓：要分開的不是「通過前、通過後」，而是「這個問題該不該修」；判準用 F6 那六種，不另立一套。
