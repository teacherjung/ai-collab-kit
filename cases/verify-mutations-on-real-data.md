# 瀏覽器驗證誤套用到真實資料

- 日期：2026-07-18
- 本文條號：乙4
- 發生什麼：實作者在瀏覽器驗證一個會寫入的一次性遷移（店名格式整理），用腳本工具模擬點擊、本想點取消；那次呼叫逾時異常，結果把遷移套用到了開發伺服器連著的真實資料庫、上百筆交易紀錄被改寫。轉換內容剛好是裁示者要的、存檔也有自動備份，但這是未經他按鈕核准的即時資料變更；已從備份完整還原並驗證。
- 代價：資料事故：真實交易資料被未經核准改寫，靠自動備份才還原。
- 教訓：驗證會寫入的功能，瀏覽器只走唯讀（預覽、計數、畫面結構），正確性靠隔離資料的考題；非跑套用不可就先問裁示者並先備份；程式化點擊可能逾時誤觸鄰近的寫入鍵，寧可只讀畫面結構。
