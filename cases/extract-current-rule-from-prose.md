# 想從散文抽出「現行規則是哪幾個字」，審了十一輪

- 日期：2026-09-08
- 本文條號：F10
- 發生什麼：一條「綁回正本」的考題想從規則書的散文裡抽出現行規則值：第一輪寫死、第二輪照舊欄名搜整節、第三輪改抽模板句裡的欄位、第四輪數反引號段數與順序，每一種都能被「同一段裡留一句『舊版寫…已停用』」騙過。為了多買一層加的字眼絆線（看到某些字就判定那段講的是舊規則），接著連兩輪誤擋現行規則的正常散文，第七輪整條拿掉並留下「為什麼拿掉、不要再加回來」。第五輪起實作者撤掉「段數加順序可證明現行身分」的封閉保證，照實劃界：守普通漂移、不守蓄意留下的舊範例，那一半交給複審。
- 代價：十一輪審查＝這一支從頭到尾的總成本，只記在這一則（同一支的那則裁示記在 [withdrawal-three-objective-reasons](withdrawal-three-objective-reasons.md)，那裡不再重複計）；前六輪都在同一個病上換形狀，第七輪第一次通過後又退回一輪。
- 教訓：「哪一段才是現行值」不是機器從散文判得出來的，第三輪同族還在被抓就該停下換做法：照實劃界、把判不動的那一半交給人；列舉補不完就整條拿掉。
