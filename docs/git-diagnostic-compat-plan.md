本人在理財優化工作線同意 Codex 承接必要套件修補；技術依據為理財 #747 的 Sol 裁示 https://github.com/teacherjung/personal-finance-webapp/pull/747#issuecomment-6446575016 。本支由 Codex 實作、Grok 正式複審，掃描依本人指示暫停。

## 驗證

- 以適用 Git 版本重現舊前提失敗，再確認修正後通過；記錄實際執行版本，不以模擬版本冒充。
- 分別核對不存在的 gitdir 指標及 HEAD 亂碼；保留其他損壞設定情境。
- 有效突變驗證錯誤放行、漏印或改寫診斷、亂給還原指令會被行為斷言攔下。
- 完整套件檢查及當版 CI 通過後，走官方 Grok 備審、獨立對帳及正式合併。
